# 디자인 컨펌 툴

디자인 요청을 수집하고 컨펌·수정 요청 상태를 관리할 수 있는 단일 페이지 도구입니다. 별도 빌드나 서버 없이 브라우저에서 바로 실행됩니다.

## 기능
- 요청 정보 입력: 제목, 요청자, 디자이너, 마감일, 자료 링크, 메모를 입력해 추가합니다.
- 상태 관리: 대기 / 수정 요청 / 컨펌 버튼으로 상태를 즉시 전환하고 최근 업데이트 시간을 표시합니다.
- 필터 & 검색: 상태 필터와 제목·요청자·디자이너 검색으로 필요한 항목만 빠르게 조회합니다.
- 요약 배지: 상태별 개수를 상단 배지로 보여줍니다.
- 로컬 스토리지 저장: 브라우저에 데이터가 저장되어 새로고침 후에도 목록이 유지됩니다. 초기화 버튼으로 기본 샘플 데이터로 리셋할 수 있습니다.

## 사용 방법
1. `index.html`을 브라우저에서 직접 열면 즉시 사용할 수 있습니다.
2. "디자인 요청 등록" 섹션에 정보를 입력하고 **요청 추가** 버튼을 클릭합니다.
3. 목록에서 **대기/수정 요청/컨펌** 버튼으로 상태를 바꾸고, 필요 시 **삭제** 버튼으로 항목을 제거합니다.
4. 상단 필터와 검색창을 이용해 원하는 항목만 확인합니다.

필요에 따라 로컬 스토리지 데이터를 삭제하고 싶다면 "모든 데이터 초기화" 버튼을 누르세요.
